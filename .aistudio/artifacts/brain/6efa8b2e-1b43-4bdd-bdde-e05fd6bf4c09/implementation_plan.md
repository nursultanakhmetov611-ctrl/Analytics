# Автономная SPA-архитектура в браузере (ТОО «ARS» · Октябрь 2026 г.)

Приложение переведено в режим **100% автономного Single Page Application (SPA)** в браузере. Полностью устранены внешние зависимости, подключение к PostgreSQL, серверные переменные окружения (`process.env`) и API-прокси. Все расчёты, пономерной учёт, матрица ремонтов, аналитический модуль и справочники работают прямо в браузере с сохранением в `localStorage` и встроенным массивом официальных данных `OCTOBER_2026_DATA`.

---

## 1. Выполненные архитектурные изменения

1. **Отключение PostgreSQL и серверных переменных окружения**:
   - Удалён модуль `src/config/env.ts` и директория `src/config/`.
   - Удалены все проверки паролей, токенов `FREELLM_*`, строки подключения `DB_URL` и черные списки секретов.
   - Очищен `.env.example`, оставлены только базовые параметры порта (`PORT=3000`).

2. **Автономность в браузере (No Server Proxies / 0 Network Calls)**:
   - В `src/App.tsx` устранены внешние вызовы `fetch('/api/data')`, `fetch('/api/references')` и `fetch('/api/analyst/query')`.
   - Исходный массив производственных показателей за 2026 год (`arsDatasetFallback`) загружается мгновенно из встроенного JSON-бандла в память браузера без ожидания сети.
   - ИИ-Аналитик (`generateAnalyticalAnswer`) исполняется на 100% на клиенте в веб-воркере/потоке браузера из `src/utils/arsEngine.ts`.
   - Справочники предприятий, видов ремонта и депо сохраняются в `localStorage` (`ars_references_2026_v1`).
   - Учётные записи пользователей (RBAC для Головного офиса и мастеров депо КВРД, АВРД, БВРД, УВРД) работают полностью в браузере с сохранением сессии в `localStorage`.

3. **Встроенные исторические данные ТОО "ARS" за ОКТЯБРЬ 2026 года**:
   - `OCTOBER_2026_DATA` полностью интегрирован в `src/components/DailyOutputView.tsx`:
     - **Посуточный выпуск за 1..21 октября (`daily_release`)**: [АВРД, БВРД, КВРД, УВРД].
     - **Ремонт колёсных пар за 3..21 октября (`daily_wheel_pairs`)**.
     - **Фактическая расстановка на 21.10.2026 (`fact_21_oct`)**:
       - 93 вагона в ожидании на станции (`AT_STATION`),
       - 20 вагонов на подходе к станции (`EN_ROUTE`),
       - 15 вагонов выпуск за смену (`RELEASE`),
       - Итого пул смены: **128 вагонов** с реалистичными 8-значными сетевыми номерами (полувагоны `6...`, крытые `2...`/`5...`, цистерны `7...`).
   - Автоматическая синхронизация матрицы ремонтов (`syncMatrixFromWagons`, `calcBranchMatrix`) с отображением сумм по ДР (42 ожид. / 12 подход), КР (46 ожид. / 8 подход) и ТОР (5 ожид.).

4. **Серверный запуск (Dev / Static SPA)**:
   - Файл `server.ts` оптимизирован до минимального Vite-раннера/статического файл-сервера SPA на порту 3000 без каких-либо баз данных и прокси-эндпоинтов.
   - Конфигурация `vite.config.ts` настроена на локальный порт `3000` и хост `0.0.0.0`.
   - Все проверки TypeScript (`tsc --noEmit`) и сборка `vite build` завершаются с кодом 0.
